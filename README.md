# Charan G Portfolio

Production-quality personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Update portfolio content in `src/data`. Replace `public/Charan_G_Resume.pdf` with the final resume when ready, and update contact links in `src/data/profile.js`.
